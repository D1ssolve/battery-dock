# Проверка поставки

## 0.4.0 — границы проверки

На коммите `55d50d2` [Windows CI 40122075835](https://github.com/D1ssolve/battery-dock/actions/runs/40122075835)
на Windows Server 2025 прошли **122 автоматических теста**, smoke-проверки
жизненного цикла Tk и единственного экземпляра, а также захват реальных окон
DEMO-приложения. Снимки в `docs/screenshots/` просмотрены вручную; показания
смоделированы. Это CI-среда, не ручная проверка Windows 11 с USB-устройствами.
В том же запуске успешно завершились сборка PyInstaller, демодиагностика готового
EXE, frozen-plugin проверки явного включения, хешей, зависаний, аварийного выхода
и очистки, упаковка с исходниками/лицензиями/хешами и загрузка артефактов.
Задача публикации релиза была намеренно пропущена: это обычная проверочная сборка,
не свидетельство опубликованного релиза. Финальный release-коммит проверяется
отдельно. Реальные USB-устройства, точность и сон/пробуждение Windows этим CI
не проверялись.


Версия 0.4.0 добавляет версионированную упаковку и управляемую публикацию.
Фикстурный тест упаковщика проверяет EXE, исходники, лицензии, версию,
внутренние хеши файлов и внешний SHA-256 ZIP без скачивания зависимостей.
Результат Windows CI необходимо проверять на точном коммите; локальные Linux
тесты не запускают реальный Windows EXE. Новый [чек-лист](WINDOWS-CHECKLIST.md)
не является отчётом о прохождении. Пользователь подтвердил начальное чтение Aerox 9 через приёмник в 0.2:
100%, `charging: false`, `connected: true`, `estimated: false`. Это не проверка
всего диапазона заряда, зарядки, ревизий или сна/пробуждения Windows.
Точность показаний и полный ручной интерфейс остаются отдельными проверками.
[Процедура выпуска](RELEASING.md) не означает, что релиз уже опубликован.

Ниже — исторический отчёт, не актуальная сертификация 0.4.0.

# Историческая проверка поставки 0.1.0

## Обновление 0.1.1 (24 октября 2026)

35 локальных автоматических тестов прошли, включая дополненную Windows HID-запись
и маркировку оценочного процента. Проверен рендеринг десяти комбинаций значков.
На момент 0.1.1 исправление Aerox 9 требовало повторной проверки на мыши;
позднее в 0.2 пользователь подтвердил начальное чтение через приёмник (см. выше). Формула G733
не изменена; расхождение с G HUB не считается исправленным.

Ниже сохранён первоначальный отчёт до Windows CI. Для актуального результата
Windows-сборки смотрите GitHub Actions на конкретном коммите.

Дата: 24 октября 2026. Среда проверки: Linux, Python 3.12.

Проверено:

- 26 автоматических тестов успешно: 11 тестов модели/настроек/уведомлений,
  10 тестов HID-парсеров и поддельных транспортов, 5 тестов потока событий UI.
- `python -m compileall -q battery_dock tests`: успешно.
- `python -m battery_dock --demo --diagnose ...`: успешно; JSON помечен `demo: true`.
- Рендеринг значков Pillow для неизвестного заряда, 0, 5, 20, 99 и 100%: успешно.
- Выполнена проверка обработки ошибок трея, отсутствующих показаний и
  исключений HID. В диагностический файл не записываются USB-пути и серийные номера.

Не проверено, не считается пройденным:

- Настоящее окно tkinter и Windows tray/уведомления на Windows 11.
- Выполнение Windows CMD/PowerShell build-скриптов и сборка PyInstaller EXE.
- Реальный обмен с G733, Aerox 9, их ревизиями и прошивками.
- Сравнение показаний с G HUB/SteelSeries GG, сон Windows, горячее подключение.
- Установка зависимостей в чистое Windows-окружение.

В исходном архиве только исходники и инструкции сборки. Собранного EXE в нём нет;
это не относится к отдельному артефакту успешной Windows-сборки GitHub Actions.
Тесты с поддельными HID-ответами не доказывают аппаратную совместимость.

## Подготовка Windows CI

Добавлены workflow GitHub Actions и упаковщик с исходниками, лицензиями и хешами.
Локально на Linux проходят 30 тестов, включая 4 теста упаковщика с фикстурами,
и compileall. Проверка упаковщика не запускает Windows EXE и не скачивает
зависимости: эти шаги должны пройти на настоящем Windows runner.
Статус конкретной сборки смотрите в GitHub Actions; исходная проверка выше
не подтверждает результат последующего CI-запуска.
